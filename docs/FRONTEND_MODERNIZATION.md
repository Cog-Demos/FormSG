## 3. Env-var rename plan (`REACT_APP_*` → `VITE_APP_*`)

Vite only exposes variables prefixed with `VITE_` via `import.meta.env`. Every
variable keeps its name with the prefix swapped; `envPrefix` stays at the
default `VITE_`.

| Old                                                                               | New                                                                                   | Read in                                                            |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| `REACT_APP_VERSION`                                                               | `VITE_APP_VERSION` (from `npm_package_version`, defined in `vite.config.ts` `define`) | `App.tsx`, `datadog-chunk.ts`                                      |
| `REACT_APP_URL`                                                                   | `VITE_APP_URL`                                                                        | `AppHelmet.tsx`, `datadog-chunk.ts`                                |
| `REACT_APP_GA_TRACKING_ID`                                                        | `VITE_APP_GA_TRACKING_ID`                                                             | `App.tsx`                                                          |
| `REACT_APP_FORMSG_SDK_MODE`                                                       | `VITE_APP_FORMSG_SDK_MODE`                                                            | `formSdk.ts`                                                       |
| `REACT_APP_GROWTHBOOK_CLIENT_KEY`                                                 | `VITE_APP_GROWTHBOOK_CLIENT_KEY`                                                      | `growthbook.ts`                                                    |
| `REACT_APP_DD_RUM_APP_ID` / `_CLIENT_TOKEN` / `_ENV` / `REACT_APP_DD_SAMPLE_RATE` | `VITE_APP_DD_RUM_APP_ID` / `_CLIENT_TOKEN` / `_ENV` / `VITE_APP_DD_SAMPLE_RATE`       | `datadog-chunk.ts`                                                 |
| `REACT_APP_*` (any other)                                                         | `VITE_APP_*`                                                                          | `ApiService.ts`, `axiosDebugFlow.tsx`, `lazyRetry.ts`, `index.tsx` |
| `process.env.NODE_ENV`                                                            | `import.meta.env.DEV` / `.PROD` / `.MODE`                                             | various                                                            |
| `process.env.PUBLIC_URL`                                                          | `import.meta.env.BASE_URL`                                                            | `index.tsx`, `serviceWorker.ts`                                    |

Owners: TICKET-A renames reads in `frontend/src` and adds `vite-env.d.ts`;
TICKET-B renames the build-time definitions in `.github/workflows/*`,
`Dockerfile.production` and `datadog-chunk.ts`. `.buildtime-env` is deleted
(TICKET-A); local overrides go in `frontend/.env.local` (git-ignored).

## 4. Phase 1 file-ownership map

Only TICKET-0 and TICKET-G may touch `frontend/package.json` /
`frontend/package-lock.json`. Dependency requests from Phase 1 go into the Jira
ticket comment and are applied in TICKET-G.

| Ticket                              | Owns                                                                                                                                                                                                                                                                                                                                                                                                     | Must not touch                                                                                     |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| A – Vite build (MBA-2854)           | `frontend/vite.config.ts` (all but `build` section), `frontend/index.html` (moved from `public/`), `frontend/tsconfig.json` (paths merged in), `frontend/src/vite-env.d.ts`, `frontend/src/**` env reads + worker/SVG import sites (`StorageResponsesService.ts`, `*.svg` imports), deletions: `craco.config.js`, `tsconfig.paths.json`, `src/setupProxy.js`, `src/react-app-env.d.ts`, `.buildtime-env` | `*.test.*`, `*.stories.*`, `.storybook/`, `.github/`, `Dockerfile*`, `datadog-chunk.ts`, `shared/` |
| B – Datadog + deploy (MBA-2855)     | `frontend/datadog-chunk.ts`, `build` section of `vite.config.ts` (rollup input/output for the separate Datadog file), `.github/**`, `Dockerfile.production`, deletion of `webpack.dd.config.js`                                                                                                                                                                                                          | everything else under `frontend/src`, `.storybook/`, tests                                         |
| C – Storybook 8 (MBA-2856)          | `frontend/.storybook/**` (→ `main.ts`, `preview.tsx`, `manager.ts`), `frontend/**/*.stories.*`, `frontend/**/*.mdx`, deletion of `frontend/__tests__/storyshots/`                                                                                                                                                                                                                                        | non-story app code, tests, configs owned by A/B/D                                                  |
| D – Vitest (MBA-2857)               | `frontend/vitest.config.ts`, `frontend/src/setupTests.ts` → `frontend/src/test/setup.ts`, `frontend/**/*.test.*`, deletion of `frontend/jest.config.js`                                                                                                                                                                                                                                                  | app code, stories, `vite.config.ts`                                                                |
| E – React 18 + Chakra v2 (MBA-2858) | `frontend/src/**` app code (components, features, theme, `index.tsx`)                                                                                                                                                                                                                                                                                                                                    | `*.test.*`, `*.stories.*`, env reads / worker / SVG import lines (A), `.storybook/`                |
| F – Shared types TS5 (MBA-2859)     | `shared/**`, backend `src/**` and `__tests__/**` consumers/fixtures, root `tsconfig*.json` if required                                                                                                                                                                                                                                                                                                   | `frontend/**`                                                                                      |

Conflict rule: if A and E must touch the same file (e.g. `index.tsx`), A owns
env/`PUBLIC_URL` lines and E owns the `createRoot` change; both keep edits
minimal so a 3-way merge is clean.
